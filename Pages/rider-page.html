About

Rider is a 2D stunt racing game with the objective to achieve the most score possible before crashing. With an endless mode, levels, challenges and leaderboards the game has a lot of different ways to challenge your skills.

Appstore

My work on it

This game is made in Unity 3D. I initially joined the game after its port from its previous implementation to Unity, once there I worked together with other devs to implement multiple meta systems and gameplay adjustments as well as fake multiplayer with leaderboards and events.

Main work on the project:

  • Working on the creation of different meta systems such as the lootboxes and Cards
  • Implementing different game modes logic
  • UI improvements
  • Creating and managing documentation for the project
  • Help mentor other developers on the project about clean coding and design patterns
