About

Rider Worlds is the sequel of the game Rider, and like its predecessor, is a 2D stunt racing game with the objective to achieve the most score possible before crashing. With an endless mode, challenges, achievements and seasonal events the game has a lot of different ways to challenge your skills.

My work on it

This game is made in Unity 3D. I joined the game to work on the new meta systems and seasonal content, once there I worked together with other devs on its multiple systems and later on took it as a stand alone dev.

Main work on the project:

  • Implementing different game modes logic
  • Seasonal cosmetic logic and wheel system
  • Taking the lead in creating documentation for the project
  • Bonus system
  • Improvements on the lootbox system
