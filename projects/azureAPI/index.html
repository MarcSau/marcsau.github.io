About

This is an interface created to interact with an API currently hosted on Microsoft Azure, this API simulates a shop backend with products, product types and transactions, you will be able to add and remove products and product types from the backend and do transactions that will affect the stock of said items and notify you of impossible requests.
Due to the limitations of the plan used in azure you might need to contact me if you want to do a tech test
