About

This is an interface created to interact with an REST API currently hosted on Microsoft Azure, said API simulates a shop backend with an SQLite database with products, product types and transactions.
You will be able to add and remove products and product types from the backend and do transactions that will affect the stock of said items and notify you of impossible requests.
Due to the limitations of the plan used in azure response might be a bit slow, if you are interested in checking the code of the API directly its currently hosted in a public git repository here
